# SPACE PC — магазин компьютеров и комплектующих

Сайт с админкой для продажи компьютерных сборок. Цены сборок считаются автоматически из прайса поставщика (AGE UZ).

## Запуск

Нужен **Node.js 24+** (используется встроенная база `node:sqlite`, внешняя БД не нужна).

```bash
npm install
npm run dev        # разработка: http://localhost:3000
npm run build && npm start   # продакшн
```

Админка: http://localhost:3000/admin — пароль задаётся в `.env.local` (`ADMIN_PASSWORD`, по умолчанию `admin`). **Перед публикацией смените `ADMIN_PASSWORD` и `ADMIN_SECRET`.**

База данных и загруженные фото лежат в папке `data/` (её нужно бэкапить). При первом запуске база заполняется стартовым каталогом: 52 комплектующие и 8 сборок на позициях AGE с фото.

## Языки и тема

Сайт на двух языках: **узбекский (латиница) — основной**, русский — по кнопке UZ/RU в шапке (запоминается в cookie `lang`). Все тексты витрины — в `src/lib/i18n/dict.ts`. У сборок в админке есть отдельные узбекские поля (название, подзаголовок, FPS, описание); если они пустые — показывается русский текст. Адрес и часы работы на узбекском — в Настройках.

Кнопка солнце/луна переключает дневную и ночную тему (cookie `theme`), цвета — в `src/app/globals.css`.

## Как устроены цены

```
цена комплектующей (сум) = цена в прайсе × курс USD        (или ручная цена в сумах)
цена сборки = Σ комплектующих × (1 + наценка %) + сборка + доп. сумма → округление вверх
```

- Курс, наценка, стоимость сборки, округление — **Админка → Настройки**. Наценку и стоимость сборки можно переопределить в каждой сборке.
- Если позиции нет в прайсе или её нет в наличии — сборка показывается «Под заказ», а в **Обзоре** админки появляется предупреждение.

## Работа с прайсом AGE UZ

1. **Админка → Прайс AGE** → загрузить файл AGE как есть (`.xlsx`; старый `.xls` пересохранить в `.xlsx`).
2. В файле AGE есть сводный лист **Export** (все позиции с ценой) — импорт берёт его. Колонки без заголовков определяются по содержимому: A — наименование, B — код, C — цена в USD. Категория (процессор, плата, видеокарта…) определяется по названию.
3. Позиции, пропавшие из нового прайса, по умолчанию помечаются «нет в наличии» — сборки с ними станут «Под заказ».
4. Кнопка **«Скачать прайс в сумах»** выгружает весь прайс с оптом и розницей в сумах по текущему курсу.

Связь «комплектующая ↔ позиция прайса» — по **коду**. У ~690 позиций AGE нет артикула — для них кодом служит полное наименование, поэтому если AGE поменяет название такой позиции, привязку нужно обновить (в «Обзоре» появится предупреждение «нет цены»).

## Курс доллара

Цены AGE в USD пересчитываются в сумы по **курсу ЦБ Узбекистана** (cbu.uz) — он подтягивается автоматически раз в 3 часа. Отключить автокурс или обновить вручную — **Настройки → Ценообразование**.

## Каталог комплектующих и фото

- **Админка → Комплектующие → «Добавить все комплектующие из прайса»** — создаёт на сайте все процессоры, платы, память, видеокарты, накопители, БП, корпуса и кулеры из прайса, которые есть в наличии (без ноутбуков, периферии, SODIMM и внешних дисков). Сокет, тип памяти, форм-фактор, мощность и объём берутся из названия позиции. Уже добавленные позиции пропускаются — кнопку можно жать после каждого нового прайса.
- **«Подобрать фото автоматически»** — ищет официальные фото: Deepcool и MSI (по модели на сайте производителя), AMD (страница процессора), Intel (значок серии), остальные бренды — через открытый каталог Icecat по артикулу. Фото сжимаются до 800px WebP и хранятся в `data/uploads/`. Позиции, для которых фото не нашлось, повторно не проверяются (есть ссылка «искать снова»).
- Чего автоматически не найти: Gigabyte без артикула (сайт блокирует ботов), Lian Li, Jonsbo, Lexar, Maxsun, FSP, Intel i9 / Core Ultra и мелкие бренды — для них фото загружается вручную в карточке (файл, ссылка или «Найти в Icecat»). На сайте вместо фото показывается иконка категории.
- Фото стартового каталога (52 позиции) лежат в `public/img/parts/`. Если у сборки нет своего фото, показывается фото её корпуса.
- **Массовый подбор фото для всего каталога** (ноутбуки, мониторы, периферия, кресла и т. д.): `node scripts/fill-photos.mjs` (поиск картинок Bing со строгой проверкой модели и цвета), для оставшихся — второй проход `node scripts/fill-photos.mjs --relaxed`. Найденное попадает в `seed-data/photo-patch*` и подставляется на сервере при следующем деплое.
- **Единый вид фото.** Все фото товаров приводятся к одному формату: квадрат 800×800, белый фон, пустые поля обрезаны, товар по центру с одинаковым отступом (`normalizeImage` в `src/lib/images.ts`, то же — при загрузке фото в админке). Старые фото переводит `node scripts/renormalize-photos.mjs` (замены — в `seed-data/photo-replace.json`, применяются на сервере при запуске). На витрине любое фото показывается через компонент `ProductImage` — рамка фиксированной формы, поэтому карточки в сетке всегда одной высоты. Новые места с фото товара делать только через него.
- Позиции прайса, у которых нет бренда в названии (Montech «TEN (B)», Thermaltake «View 71TG», Cooler Master, PowerCase…), разбираются правилами `RULES` в `src/lib/storeImport.ts`: бренд дописывается в название, категория и тип ставятся по листу прайса.

## Продажа комплектующих по отдельности

- **/parts** — каталог по категориям, **/parts/<категория>** — список с фильтрами (бренд, сокет, тип памяти, объём, мощность, цена), поиском и страницами. **/part/<id>** — карточка товара: фото, характеристики, «В корзину», «Купить в 1 клик» и подбор совместимого (платы под сокет процессора, память под плату, БП нужной мощности к видеокарте).
- **Корзина** хранится в браузере покупателя, цены и наличие при открытии корзины и при оформлении всегда пересчитываются на сервере. Заказ приходит в админку и Telegram как «Комплектующие (N шт.)» с артикулами.
- В каталоге показываются все активные комплектующие с ценой. Скрыть товар — снять «Активна» в его карточке.
- Наценка для отдельной продажи — **Настройки → «Наценка при продаже по отдельности»** (пусто — как в сборках).

## Разделы админки

- **Обзор** — новые заказы, сборки с проблемами, детали без цены.
- **Заказы** — заявки с сайта, смена статуса. Уведомления в Telegram — в Настройках (токен бота + ID чата).
- **Сборки** — состав, фото, FPS, описание, наценка; видна себестоимость и маржа.
- **Комплектующие** — привязка к прайсу и характеристики (сокет, тип памяти, форм-фактор, мощность) для проверки совместимости в конфигураторе.

## Хостинг (Railway)

Сайт развёрнут на Railway: проект **usta-pc** (название проекта в Railway осталось прежним, на сайт не влияет), сервис **web**, сборка по `Dockerfile` (Node 24).

- База и загруженные фото лежат на постоянном диске Railway, смонтированном в `/data` (переменная `DATA_DIR`). Повторные деплои их не трогают.
- Пароль админки — переменная `ADMIN_PASSWORD` в Railway (сервис web → Variables), секрет сессий — `ADMIN_SECRET`.
- **Обновить сайт после изменений в коде:** закоммитить и сделать `git push` в ветку `main` репозитория https://github.com/uiminov/space-pc — Railway сам соберёт и выложит новую версию (автодеплой из GitHub, сервис web → Settings → Source). Запасной способ без GitHub: из папки `pc-store` выполнить `railway up` (CLI: https://docs.railway.com/cli).
- `seed-data/` — снимок локальных данных, который копируется на пустой диск при самом первом запуске. Обновить снимок: `npm run snapshot` (заказы и токены Telegram в него не попадают). На уже работающий сервер снимок не влияет.
- Домен space-pc.uz подключается DNS-записями у регистратора (CNAME на адрес Railway + TXT для подтверждения).

## Поставщики: AGE и Darian

- Позиции всех прайсов лежат в `price_items` (поле `supplier`). Коды Darian хранятся с приставкой `darian:` (`lib/suppliers.ts`).
- Один товар сайта может иметь предложения нескольких поставщиков (`component_offers`). Цена считается по главному поставщику (выбор на странице «Прайс Darian»), если у него есть в наличии, иначе — у следующего (`resolveOffers`).
- Прайс Darian (`/admin/prices/darian`): разбор файла и сопоставление с товарами AGE — `lib/darian.ts`. Совпадения по модели и конфигурации (процессор, память, накопитель, видеокарта, цвет, диагональ, частота) привязываются сами, сомнительные — в «Проверьте совпадения». Позиции без цены («.») на сайт не выходят.
- Сравнение цен для закупщика: `/admin/compare` — модели по одной в строке, лучший вариант (в наличии и дешевле) и итог по списку.
- Первая выкладка прайса Darian на сервер: `node scripts/darian-seed.mjs "прайс.xlsx"` → `seed-data/prices/darian.json`, сервер загрузит его при запуске один раз. Дальше прайс обновляют загрузкой файла в админке.
- Фото для новых товаров Darian: `node scripts/fill-photos.mjs --supplier darian`.
